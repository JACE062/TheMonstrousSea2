# Pause menu verification — 25 October 2026

Completed implementation receipt for FUT-07. Current behavior belongs to
[Current game](../../CURRENT_GAME.md#persistence-and-presentation); remaining
command-station design belongs to [the backlog](../../BACKLOG.md#pt2-11--combat-ui-does-not-function-as-a-readable-command-station).

## Delivered and verified

- Esc and the on-screen pause icon open Resume, Settings, lineage identity and
  explicit save/return/exit actions. The persistent lineage/Title Menu row is
  removed; the Chronicle remains directly accessible in battle.
- Nested settings and belt-help dialogs consume Esc before gameplay. Resume
  restores prior focus when it survives; pointer and keyboard gameplay input are
  blocked while the menu is open. Saving also blocks dismissal and duplicate actions.
- Departure uses the existing supported-stop whitelist and waits for playback.
  Queued saves drain before navigation or native exit, with retryable save/exit
  failures. Dialog listeners are removed before the lineage route can dispose
  its controller. Unsaved scenarios never persist on exit.
- A real fatal volley completes behind Pause. A forced parent rebuild retains
  the same battle/game until playback and its ending delay finish, then reaches
  loot. Resume does not repeat damage, logs, loot or gold rewards.
