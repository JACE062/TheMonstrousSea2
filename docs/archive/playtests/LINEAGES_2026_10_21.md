# Title menu and independent lineages — 21 October 2026

FUT-06 step 2 adds Continue, New Lineage, Settings and Exit to normal startup. Separate save labels do not set permanent family surnames. Completed hunts stay viewable, and a new lineage starts with a fresh Standard-only profile. Alternate-fate branching, slot deletion/renaming and Ancestral Chronicles are not delivered here.

## Persistence and navigation

- `LineageStore` owns a validated catalog and per-ID save directories. Labels never become path components. Writes are serialized within the app and catalog publication uses a flushed temporary file followed by rename.
- Existing single-save bytes are validated and copied once to Original Lineage after the existing Documents import. Source files remain backups. A pending import can retry, and a missing catalog beside populated slots cannot silently overwrite them from stale backups. An existing catalog remains authoritative.
- Slot profile/checkpoint reads report corruption; a damaged slot is disabled with retry while healthy lineages remain selectable. Catalog/open/create errors do not enter gameplay as a fresh profile. Tests use temporary roots or in-memory storage; no player save was migrated, reset or repaired during verification.
- Slot controllers retain home preparation and ordinary death's exact offered heirs. Direct-controller compatibility fixtures retain their previous deletion policy. Menu departure finishes queued saving, blocks gameplay input and disposes the controller only after the route unmounts. Ending read state/rewards remain intact.
- Departure is limited to fully supported save phases. Combat, island, shrine and smuggler screens require proceeding to Set Course; no individual-turn combat save is claimed. A nested navigator preserves F10/the debug launcher during normal play. The completed-hunt screen also offers Return to Menu.
